# Bini — team Opus Carlsen's AI Chessathon agent

Everything in `bini/` is our own code, written for this event. No third-party engine, network,
or lookup table of engine moves is used or shipped. The plan, decisions and build log are in
[PLAN.md](PLAN.md).

## Layout

| Path | What |
|---|---|
| `bini/agent.py` | competition entry point: `get_move(fen, time_left_ms)`; game-history reconstruction, clock budget, legality check, python-chess fallback |
| `bini/bini_board.py` | bitboard position, magic-bitboard move generation, make/unmake, Zobrist hashing (numba) |
| `bini/bini_magics.py` | magic multipliers generated by `tools/find_magics.py` |
| `bini/bini_eval.py` | hand-crafted tapered evaluation (fallback when no network is shipped) |
| `bini/bini_search.py` | PVS/alpha-beta with TT, null-move + verification, LMR/LMP, futility, SEE, quiescence, repetition detection |
| `bini/bini_nnue.py` | NNUE-style evaluation (768 features x 2 perspectives -> 256 -> 1), int16 weights, incremental accumulators, safetensors reader |
| `bini/bini_engine.py` | iterative deepening driver, aspiration windows, time control, warm-up (compile) |
| `bini/tools/` | data streaming from the Lichess evaluation database (CC0), NNUE training + quantised export, parallel arena, telemetry, packaging |
| `bini/tests/` | perft + differential legality test vs python-chess, search/mate/tactics tests, NNUE exactness test, wrapper tests |
| `aichessathon-starter/` | the organisers' harness (MIT), vendored unchanged |

## How the network was trained

`tools/stream_lichess.py` streams positions and Stockfish evaluations from
`lichess_db_eval.jsonl.zst` (Creative Commons CC0), keeping the deepest evaluation per position
(depth >= 12) and flagging quiet positions (best move neither a capture nor a promotion).
`tools/train_nnue.py` trains the network in PyTorch on the M2 GPU: 8 king buckets x 768
piece-square features per perspective (6,144 inputs), 512 hidden units, one-cycle schedule, MSE
loss on sigmoid(cp/400) from the side to move's view, 8 epochs over ~128M quiet positions. Export
quantises to int16 (input layer x255, output layer x QB x 400 with QB chosen so nothing saturates)
and writes `nnue.safetensors` (6.3 MB). `tests/test_nnue.py` checks that the numba integer
forward pass with incremental updates matches a reference implementation exactly, and
`tests/test_train_consistency.py` checks the PyTorch model and the engine agree to within
quantisation error. The shipped net (v2, 6 Sept 2026) scored 75.8% over 200 games against the
same engine with the hand-crafted evaluation.

## Verify locally

```
cd aichessathon-starter && make setup            # exact platform stack via uv
cd ../bini
../aichessathon-starter/.venv/bin/python tests/test_board.py 20000
../aichessathon-starter/.venv/bin/python tests/test_search.py
../aichessathon-starter/.venv/bin/python tests/test_nnue.py
../aichessathon-starter/.venv/bin/python tools/arena_par.py --agent . --opponent ../aichessathon-starter/baselines/minimax --games 100
bash tools/package.sh                            # submission.zip with agent.py at the root
```
